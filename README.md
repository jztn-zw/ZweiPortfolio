# Developer Portfolio

A responsive portfolio built with React, TypeScript, Vite, Tailwind CSS v4, and Lucide React. The hero and journey use Jaztin Abram Contreras's supplied information. GreenWay is completed and links to its live website. Two project entries, social profile URLs, and the university name remain placeholders.

## Development

```sh
npm install
npm run dev
```

## Checks and production build

```sh
npm run lint
npm test
npm run test:spider
npm run build
npm run preview
```

The build command runs TypeScript checks before generating `dist/`. The spider geometry checks use Node.js 22+ type stripping and cover fixed limb lengths, upward knee arches, opposing gait phases and bounded turns.

## Source structure

Section entrances use `src/hooks/useScrollReveal.ts` and `src/components/ScrollReveal.css`. Headings unfold through a diagonal mask, panels settle from alternating sides with a slight tilt, artwork lifts into place, and project cards arrive in a short cascade. Section numbers receive a brief crimson sweep alongside the checker-detail wipe. Native viewport observation triggers the sequence once per page visit across Home, Skills, and GreenWay. Existing first-screen content and direct anchors stay visible immediately; keyboard focus finishes a pending reveal. Phones use smaller movements without panel rotation, reduced-motion preferences disable the effects, and printing shows all content. Native smooth anchor scrolling and the existing hover/drag interactions remain in place.

- `src/pages/Home.tsx`: page composition and project selection.
- `src/data/portfolio.ts`: editable placeholder content.
- `src/components/`: shared top header and icon navigation, project cards and dialog, section headings, footer, and original vector artwork.
- `src/index.css`: theme, layout, responsive rules, and reduced-motion support.

The hero portrait is a transparent PNG adapted from the supplied illustration using the built-in imagegen tool. Its edit prompt is documented in `docs/hero-artwork.md`. Project artwork is generated locally as SVG. The page does not depend on stock imagery, external fonts, or an animation library.

The hero's `PortraitReveal` control previews the real portrait on mouse hover. Click or tap to keep it visible, then click or tap again to return to the illustration. Enter and Space work through the native button. The photo loads before interaction is enabled. Complementary SVG pixel masks reveal the photo from head to bottom and return to the illustration from bottom to head, while the crimson backdrop stays fixed. Image-textured fragments scatter and assemble along the changing edge, accented by small crimson, cream, and muted pixels. A single 1.4-second Web Animations timeline drives the masks and fragments through an inherited CSS progress property. Leaving midway reverses that timeline from its current position; hovering again resumes forward without restarting. The tiled masks and fragments are hidden at rest for a seamless portrait. Both portrait images stay aligned and retain their original appearance. Reduced-motion preferences switch instantly without particles. Small-screen hero backgrounds remain static and subtle.
