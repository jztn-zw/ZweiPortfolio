# Technology brand icons

Local monochrome SVG sprite used by the minimal skills page. React Native uses the React brand mark. Source view boxes and path geometry are preserved; title nodes are omitted because the adjacent text names each technology.

Simple Icons source icons are distributed under CC0. Lobe Icons assets retain their MIT license in public/tech-icons-LICENSE.txt. Brand names and marks remain the property of their owners.
